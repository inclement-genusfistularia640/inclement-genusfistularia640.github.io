🔍 Frequently Asked Questions

Do I need to know how to code to use this?

No. The software provides a standard interface for managing your data. You do not need to write code to perform searches or run basic tests.

Where does the data come from?

The engine connects to public market data sources to download historical information for A-share markets and ETFs.

Is my data private?

Yes. Because the software saves data to your local machine, your study records and indicator settings remain on your hard drive.
